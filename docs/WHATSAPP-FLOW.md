# WhatsApp enquiry flow
1. Shopper opens a product and chooses Enquire on WhatsApp.
2. Server validates product name and optional notes.
3. Server generates a wa.me URL using NEXT_PUBLIC_WHATSAPP_NUMBER.
4. Shopper reviews and sends the message in WhatsApp.
5. AYC confirms price, availability, sizing, fulfilment and payment instructions. Opening WhatsApp never confirms or pays for an order.
