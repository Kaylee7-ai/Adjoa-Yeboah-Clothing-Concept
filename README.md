# Adjoa Yeboah Clothing — Next.js storefront concept

Independent, uncommissioned concept. It is **not an official brand website** until the business authorizes and approves it.

## Stack
Next.js App Router, React, TypeScript, Tailwind CSS, Prisma and a PostgreSQL-ready data model.

## Routes
- Home, shop catalogue and dynamic product details
- Lookbook, bridal, about and press
- Appointment request page
- Cart, checkout and wishlist placeholder pages
- API scaffolds for WhatsApp enquiries and appointment requests

## Setup
See [docs/SETUP.md](docs/SETUP.md). Copy `.env.example` to `.env.local`, configure PostgreSQL, install dependencies and run the development server.

## Current limitations
The catalogue is provisional. Displayed prices are examples and all fashion photography is illustrative stock, not verified AYC product photography. Cart persistence, customer authentication, admin product management, order processing, order tracking, appointment storage and payment processing are not connected yet. Payment credentials are placeholders. Do not collect real customer or payment data.

Verify contact details and obtain written brand approval, approved images, product information and policies before launch. GitHub Pages cannot host this full-stack Next.js application; deploy to a Next.js-compatible host after configuration and testing.
